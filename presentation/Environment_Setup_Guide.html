⚙️ Environment Setup Guide

Step-by-step instructions to set up Migration Validator on your local machine

⏱️ Estimated Time: 30-45 minutes

0

Prerequisites Checklist

Before starting, ensure you have the following:

  • ✓ Python 3.10 or higher - Runtime environment Required
  • ✓ Git - For cloning the repository Required
  • ✓ VPN Access - Required for DIAL AI service Required
  • ✓ Microsoft ODBC Driver 18 - For MSSQL connectivity For MSSQL
  • ✓ DIAL API Key - AI service access Required
⚠️ Important The Migration Validator requires a valid DIAL_API_KEY for operation. There is no fallback to rule-based generation. Contact your team lead to obtain access.
1

Clone the Repository 2 min

Open PowerShell or Command Prompt and run:

# Clone the repository
git clone https://github.com/your-org/migration-validator.git

# Navigate to the project directory
cd migration-validator

# Verify the folder structure
dir
# You should see: src/, config/, docs3.1/, requirements.txt, etc.
2

Create Virtual Environment 2 min

A virtual environment isolates project dependencies from your system Python:

# Create a virtual environment
python -m venv venv

# Activate the virtual environment (Windows)
venv\Scripts\activate

# Activate the virtual environment (Linux/macOS)
source venv/bin/activate

# Verify activation - you should see (venv) in your prompt
(venv) C:\migration-validator>
💡 Tip Always activate the virtual environment before running any Python commands for this project.
3

Install Python Dependencies 5 min

Standard Installation

# Install all required packages
python -m pip install -r requirements.txt

For Python 3.13/3.14 (Recommended)

# Use binary wheels only (faster, avoids build errors)
python -m pip install --only-binary=:all: -r requirements.txt
📦 Key Packages Installed
  • openai - DIAL AI communication
  • python-dotenv - Environment variable loading
  • psycopg2-binary - PostgreSQL driver
  • pyodbc - MSSQL driver
  • snowflake-connector-python - Snowflake driver
  • boto3 - AWS Athena driver
  • pandas, pyyaml, pydantic
4

Install Microsoft ODBC Driver (For MSSQL) 5 min

Required only if connecting to Microsoft SQL Server:

Download & Install

  1. Visit: Microsoft ODBC Driver Downloads
  2. Download ODBC Driver 18 for SQL Server
  3. Run the installer and follow the prompts

Verify Installation

# Open ODBC Administrator
odbcad32

# Look for "ODBC Driver 18 for SQL Server" in the Drivers tab
5

Configure Environment Variables 10 min

Create .env File

# Copy the example file
copy .env.example .env

# Open in your preferred editor
notepad .env
🔒 Security Warning Never commit the .env file to version control. It contains sensitive credentials.

🐘 PostgreSQL Source (SRC_1)

SRC_1_TYPE=postgresql
SRC_1_HOST=your-postgres-server.example.com
SRC_1_PORT=5432
SRC_1_DATABASE=your_database
SRC_1_SCHEMA=public
SRC_1_USERNAME=your_username
SRC_1_PASSWORD=your_password

🔷 Microsoft SQL Server Source (SRC_2)

SRC_2_TYPE=mssql
SRC_2_HOST=your-mssql-server.example.com
SRC_2_PORT=1433
SRC_2_DATABASE=your_database
SRC_2_SCHEMA=dbo
SRC_2_USERNAME=your_username
SRC_2_PASSWORD=your_password
SRC_2_AUTH=sql

For Windows Authentication, use: SRC_2_AUTH=windows

☁️ AWS Athena Source (SRC_3)

SRC_3_TYPE=athena
SRC_3_REGION=eu-north-1
SRC_3_DATABASE=your_catalog_database
SRC_3_QUERY_RESULT_LOCATION=s3://your-bucket/athena-results/
SRC_3_USERNAME=your_aws_access_key
SRC_3_PASSWORD=your_aws_secret_key

❄️ Snowflake Target

SNOWFLAKE_ACCOUNT=YOUR_ORG-YOUR_ACCOUNT
SNOWFLAKE_DATABASE=YOUR_DATABASE
SNOWFLAKE_SCHEMA=YOUR_SCHEMA
SNOWFLAKE_USERNAME=your_username
SNOWFLAKE_PASSWORD=your_password
SNOWFLAKE_WAREHOUSE=COMPUTE_WH
SNOWFLAKE_ROLE=your_role
⚠️ Account Format Use hyphen format: ORG-ACCOUNT (e.g., ZJAUJWQ-EP12783)
Do NOT use dot format (ORG.ACCOUNT) - it will fail!

🤖 AI Service (DIAL) - REQUIRED

DIAL_API_KEY=your_dial_api_key
DIAL_API_BASE=https://ai-proxy.lab.epam.com
DIAL_API_VERSION=2025-04-01-preview
DIAL_MODEL=gpt-4o
6

Verify Installation 5 min

Run these verification tests in order:

Test 1: Unit Tests (No DB/API required)

python -m pytest -q

# Expected: All tests pass
# ......................... 25 passed in 1.23s

Test 2: Lint Configuration Files

python src\validate_cli.py lint

# Expected: No errors found

Test 3: Test Database Connections

python test_env_connections.py

# Expected Output:
# PostgreSQL  PASS
# MSSQL       PASS  
# Snowflake   PASS
# Athena      PASS

Test 4: Verify AI Service Access

python src\validate_cli.py list-models

# Expected: List of available models including gpt-4o
✅ Success! If all tests pass, your environment is ready. You can now use the Migration Validator!
7

Quick Start - First Validation 5 min

Launch Interactive CLI

python src\validate_cli.py

# Interactive menu will appear:
# [1] Test Connections
# [2] Single Table Validation
# [3] Run Multiple Tables
# ...

Or Run Direct Command

python src\validate_cli.py generate ^
  --source 2 ^
  --pg-table Addresses ^
  --sf-table ADDRESSES ^
  --pg-schema dbo ^
  --sf-schema YOUR_SCHEMA ^
  --sf-database YOUR_DATABASE

🔧 Common Issues & Solutions

Issue Solution
DIAL_API_KEY is not set Add DIAL_API_KEY to your .env file and ensure VPN is connected
Snowflake connection fails Use hyphen format: ORG-ACCOUNT, not ORG.ACCOUNT
MSSQL Pre-Login failure Install Microsoft ODBC Driver 18 and verify SRC_2_AUTH
UnicodeEncodeError Run: $env:PYTHONIOENCODING = "utf-8"
Package build fails Use: pip install --only-binary=:all: -r requirements.txt
