🔧 Quick Troubleshooting

ErrorFix
DIAL_API_KEY not set Set in .env + VPN
AI failed 3 attempts Exclude column or use gpt-4o
Snowflake fails Use ORG-ACCOUNT format
MSSQL Pre-Login Install ODBC Driver 18
UnicodeEncodeError $env:PYTHONIOENCODING="utf-8"
Coverage UNKNOWN Regenerate table plan

🐍 Python API Quick Start

from src.validation.validation_executor import ValidationExecutor

executor = ValidationExecutor(base_dir=".")
results = executor.execute_batch(
    layer="bronze",
    tables=["all"],  # or ["table1", "table2"]
    validation_types=["count_validation", "data_validation"],
    config_dir="config",
)

📋 Validation Types

Count Validation
  • Compares row counts
  • Quick data loss check
  • Fast execution
Data Validation
  • Row-by-row comparison
  • Normalization applied
  • Mismatch CSV output
